# jma-skill

気象庁の天気予報を取得する。

エリア名からエリアコードを検索し、短期予報の天気・風・波・降水確率・気温を取得する。

## インストール

### gh skill

```bash
gh skill install high-u/jma-skill jma-forecast
```

### npx skills

```bash
npx skills add high-u/jma-skill
```

## 利用している API

| 用途 | URL |
|---|---|
| エリア一覧 | `https://www.jma.go.jp/bosai/common/const/area.json` |
| 天気予報 | `https://www.jma.go.jp/bosai/forecast/data/forecast/<エリアコード>.json` |
